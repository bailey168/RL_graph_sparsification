Title: Optimizing Brain Graph Sparsification with Deep Reinforcement Learning for Interpretability and Cognitive Prediction Cognitive deficits are a central feature of many psychiatric disorders and a hallmark of typical and pathological aging. Identifying reliable neurobiological markers of cognition is important for understanding brain function and developing methods to predict cognitive deficits. Resting-state functional connectivity (FC), which uses an MRI to capture time-coordinated activity between brain networks, has often shown strong performance for individualized prediction of behavioural and cognitive traits [1], [2]. FC can be represented as a graph, where nodes correspond to different brain networks and edges represent their functional connectivity. Graph neural networks (GNNs) can leverage these relationships to predict cognitive performance. However, FC graphs are often densely connected, and GNNs are difficult to interpret, making it challenging to identify which connections contribute most strongly to cognition.Graph sparsification, which selectively removes graph edges and nodes, may improve predictive performance by reducing irrelevant information while producing more interpretable graphs. A previous study has demonstrated the potential of reinforcement learning (RL) to sparsify brain connectivity graphs for input into GNN classifiers and observed better mild cognitive impairment classification [3]. However, this study has a very small sample size and they sparsified by removing entire nodes. Building on this approach, we propose a deep RL framework that performs individual edge-level sparsification to optimize FC graphs for cognitive performance prediction using a large-scale dataset. This approach aims to preserve informative connections while identifying functional networks associated with cognition. For this project, we will use the UK Biobank neuroimaging cohort for this project, which contains demographic and resting-state FC data for over 65,000 participants. This dataset will be accessed through the Centre for Addiction and Mental Health (CAMH). Four cognitive assessments will be used as prediction targets, including fluid intelligence, paired associate learning, symbol digit substitution, and trail making. Preliminary analyses showed that conventional sparsification that retained the edges based on top-k edge weights reduced GNN predictive performance, motivating the development of a more adaptive approach.Our proposed deep RL framework will use Soft Actor-Critic (SAC), an off-policy deep RL algorithm [4], with a discrete-action adaptation [5]. The RL agent will learn to selectively retain or remove individual edges from participant-specific FC graphs. A GNN will then use the sparsified graphs to predict cognitive performance. The primary reward will be based on prediction accuracy, encouraging the agent to preserve connections that improve cognitive prediction. We will additionally investigate incorporating graph sparsity into the reward function to balance predictive performance against the number of retained edges. Varying the reward weights will allow us to examine the trade-off between these objectives.We will initially develop and evaluate the framework using a smaller 21-component FC representation (21 nodes) and subsets of participants (n=10,000) before scaling to larger datasets (n=65,000) and the 55-component FC representation. Model training will require GPU computing resources for the RL agent and GNN. We will also compare RL-based sparsification against non-RL baselines, including random edge removal, edge-weight thresholding, and existing learning-based graph sparsification methods [6].The expected outputs of this project will include an RL-based graph sparsification framework, comparisons of predictive performance and graph sparsity across methods, and analyses of the resulting connectivity patterns. By examining connections consistently retained across participants, we aim to identify functional networks associated with cognitive performance and compare them with existing neuroimaging literature. Overall, this project will investigate whether deep RL can produce more informative and interpretable brain connectivity representations than conventional graph sparsification approaches.[1]	E.
